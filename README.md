# Willie Harris

I'm a computer science graduate from North Carolina State University with a concentration in cybersecurity. My interests span software development, Linux systems, networking, security, and automation.

Much of my recent work has grown out of building and maintaining my own infrastructure, from multi-site networking and VPN routing to self-hosted services. I enjoy understanding how systems work, solving practical problems, and turning those solutions into reusable, well-documented tools.

## Projects

### [Kamui Routing](https://github.com/wdharri2/kamui-routing)

A collection of Linux policy-routing controllers developed from my own multi-site network infrastructure. Kamui uses WireGuard, routing tables, NAT, and firewall rules to selectively direct traffic through remote Internet exits.

The project focuses on practical networking challenges, including traffic isolation, routing control, and predictable failure behavior.

### [AssemBliss](https://github.com/assembliss/AssemBliss)

A Visual Studio Code extension for assembling, executing, and debugging ARMv8 assembly on systems without native ARMv8 support, using the Qiling emulation framework.

I'm a maintainer of the project, which combines developer tooling, emulation, and low-level programming.

### [Seminal Input Feature Detection Tool](https://github.com/wdharri2/Seminal-Input-Feature-Detection-Tool)

An academic software analysis project exploring techniques for identifying influential input features through LLVM-based instrumentation and profiling.

### [Capture the Flag Writeups](https://github.com/wdharri2/CTFs)

Documentation of cybersecurity challenges, techniques, and problem-solving approaches from CTF competitions.
